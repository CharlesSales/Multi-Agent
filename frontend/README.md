# Frontend (Next.js)

Project scaffolded as a minimal Next.js frontend to talk to the existing backend.

Run locally:

```bash
cd frontend
npm install
# set backend URL if needed
# Windows PowerShell: $env:NEXT_PUBLIC_BACKEND_URL='http://localhost:3001'
npm run dev
```

The app uses `NEXT_PUBLIC_BACKEND_URL` (default `http://localhost:3001`).
